# Install MyX in Chrome

**[Download MyX for Chrome (.zip)](https://github.com/MattChenyuanZhang/myx/releases/latest/download/myx-extension.zip)**

No GitHub account, OpenAI account, API key, or command line is required.

1. **Unzip the download.** Keep the extracted folder in a permanent place, such as Documents. It contains `manifest.json` and `START-HERE.html`.
2. **Load it in Chrome.** Paste `chrome://extensions` into Chrome’s address bar. Turn on **Developer mode**, choose **Load unpacked**, and select that extracted folder.
3. **Open X.** Sign in at [x.com](https://x.com/home#myx), refresh the tab, and click **MyX** in the lower right or in Chrome’s Extensions menu.

In MyX, open **Feed sources** to collect Following and For You. Each person uses their own X session.

Open `START-HERE.html` inside the download for a browser-readable guide with a button to copy the extensions address.

This ZIP is an unpacked extension. It cannot be installed by double-clicking the ZIP. Normal “Add to Chrome” installation requires a Chrome Web Store listing.

To update, download the latest ZIP, replace the files in the same installed folder, click MyX’s circular **Reload** arrow in `chrome://extensions`, and refresh X. Don’t delete or move the installed folder while using the extension.
