MyX

Your following feed, in time order. Use your own X account.

1. Keep the unzipped folder

Extract myx-extension.zip. Keep the extracted folder somewhere permanent, such as Documents. It contains manifest.json and this guide.

2. Load it in Chrome

Paste chrome://extensions into Chrome’s address bar and press Enter.

Turn on Developer mode at the top right. Click Load unpacked and select the extracted folder containing manifest.json.

3. Open X

Visit x.com, sign in to your X account, and refresh the tab. Click MyX in the lower-right corner, or open MyX from Chrome’s Extensions menu.

Use Feed sources to collect Following and For You. In Feed settings, drag Discovery share to choose a 0–100% target. The default is 10 following activities plus 1 discovery post. Your mix is saved per X account; discovery needs eligible posts from your own For You feed.

No OpenAI account, API key, or GitHub account is required.

This is an unpacked Chrome extension. A Chrome Web Store listing is needed for the normal “Add to Chrome” installation. Each person installs their own copy and signs in directly on X.

Updates: download the latest ZIP, replace the files in this same folder, then click MyX’s Reload arrow in chrome://extensions and refresh X. Latest release · Source code
